## 1. 文档说明

本文档在《需求文档》基础上，描述用户端 **页面跳转关系、业务操作流程、状态流转与异常分支**，供产品、设计、开发、测试联调使用。

**图例约定：**

| 符号 | 含义 |
|------|------|
| 菱形 | 判断/分支 |
| 矩形 | 页面或操作 |
| 圆角矩形 | 开始/结束 |
| 虚线框 | 可选路径或后台处理 |

## 2. 应用总览流程

### 2.1 启动与 Tab 导航

```mermaid
flowchart TD
    Start([打开应用]) --> Index[探索首页<br/>pages/index/index]
    Index --> Tab{底部 Tab}
    Tab -->|探索| Index
    Tab -->|朋友圈| Msg[宠物朋友圈<br/>pages/msg/msg]
    Tab -->|岛宅| Island[岛宅<br/>pages/island/island]
    Tab -->|商城| Shop[商城<br/>pages/shop/shop]
    Tab -->|我的| My[我的<br/>pages/my/my]

    Index --> SubPages[分包页面 packageA]
    Msg --> SubPages
    Island --> SubPages
    Shop --> SubPages
    My --> SubPages
```

### 2.2 登录拦截通用流程

所有需登录操作统一经 `ensureLogin()` 拦截：

```mermaid
flowchart TD
    Action([用户触发需登录操作]) --> Check{本地有 token?}
    Check -->|是| Proceed[继续业务流程]
    Check -->|否| Login[跳转登录页<br/>packageA/login/index]
    Login --> LoginOk{登录成功?}
    LoginOk -->|是| SaveToken[写入 token 至本地]
    SaveToken --> Proceed
    LoginOk -->|否| StayLogin[停留登录页<br/>Toast 提示错误]
```

**触发登录拦截的典型场景：** 点赞、评论、发布动态、投诉、投喂、集市购买、打榜、领养申请、我的页菜单、支付等。

## 3. 账号体系流程

### 3.1 登录流程

```mermaid
flowchart TD
    Enter([进入登录页]) --> Mode{登录方式}
    Mode -->|手机号+密码| Pwd[输入手机号/密码]
    Mode -->|验证码| Code[输入手机号/验证码]
    Mode -->|微信| Wx[微信授权]
    Mode -->|忘记密码| Forgot[忘记密码页<br/>login/forgot]
    Mode -->|注册| Register[注册页<br/>login/register]

    Pwd --> Submit1[提交登录接口]
    Code --> SendCode{获取验证码}
    SendCode -->|60s 内| Wait[按钮倒计时禁用]
    SendCode -->|可发送| Sms[发送短信]
    Sms --> Submit2[提交验证码登录]
    Wx --> Submit3[提交微信登录]

    Submit1 --> Result{code=0?}
    Submit2 --> Result
    Submit3 --> Result
    Result -->|成功| Token[保存 token]
    Token --> Back([返回来源页/首页])
    Result -->|失败| Toast[Toast 错误信息]
```

### 3.2 注册与找回密码

```mermaid
flowchart LR
    Login[登录页] --> Register[注册页]
    Register --> Fill[填写手机号/验证码/密码]
    Fill --> RegSubmit[提交注册]
    RegSubmit --> RegOk{成功?}
    RegOk -->|是| Login
    RegOk -->|否| Toast1[提示错误]

    Login --> Forgot[忘记密码]
    Forgot --> Reset[验证手机号并重设密码]
    Reset --> ForgotOk{成功?}
    ForgotOk -->|是| Login
    ForgotOk -->|否| Toast2[提示错误]
```

### 3.3 退出与注销

```mermaid
flowchart TD
    Settings[设置页] --> LogoutChoice{用户操作}
    LogoutChoice -->|退出登录| Confirm1[确认退出]
    Confirm1 --> ClearToken[清除 token]
    ClearToken --> Guest([未登录态])

    LogoutChoice -->|账号注销| Confirm2[二次确认]
    Confirm2 --> CancelApply[提交注销申请]
    CancelApply --> CancelResult{审核/处理结果}
    CancelResult -->|成功| ClearToken
    CancelResult -->|失败| Toast[提示原因]
```

### 5.3 动态审核状态机

```mermaid
stateDiagram-v2
    [*] --> 待审核: 用户发布
    待审核 --> 已通过: 管理端审核通过
    待审核 --> 已拒绝: 管理端审核拒绝
    已通过 --> 待审核: 用户编辑后重新提交
    已拒绝 --> 待审核: 用户修改后重新提交
    已通过 --> [*]: 用户删除
    已拒绝 --> [*]: 用户删除
    待审核 --> [*]: 用户删除
```

| 状态值 | 含义 | 用户可见行为 |
|--------|------|--------------|
| 0 | 待审核 | 仅自己可见；我的动态 Tab 展示 |
| 1 | 已通过 | 出现在公共朋友圈流 |
| 2 | 已拒绝 | 展示 rejectReason；可编辑重提 |
