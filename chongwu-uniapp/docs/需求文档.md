## 1. 产品定位

「和它交个朋友」是一款面向宠物门店与养宠用户的综合应用，核心主张 **理性养宠、降低遗弃**。用户可在应用中：

- 浏览线下门店与门店宠物，参与领养与互动；
- 在「宠物朋友圈」发布、浏览动态并参与社交；
- 在「岛宅」虚拟养成宠物，完成任务、投喂、购买道具；
- 在商城购买商品、使用积分兑换周边；
- 管理个人资产、券包、助力记录与投诉等。

## 3. 功能需求详述

### 3.1 探索（首页）— `pages/index/index`

#### 3.1.1 页面目标

作为应用启动页，向用户展示品牌主张、当前城市门店入口及运营活动，引导用户进入领养、朋友圈、社群等核心功能。

#### 3.1.2 功能清单

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| H-01 | 城市切换 | 顶部展示当前城市，点击弹出城市选择器；切换后刷新门店与 Banner 数据 | P0 |
| H-02 | 运营 Banner | 展示「理性养宠」等主 Banner，点击跳转领养列表或配置链接 | P0 |
| H-03 | 线下门店网格 | 展示当前城市门店卡片（图标+名称），点击进入门店详情/小伙伴列表 | P0 |
| H-04 | 门店快捷筛选 | 横向 Pill 展示更多门店，点击同样进入门店页 | P1 |
| H-05 | 门店动态卡片 | 展示重点门店封面、营业状态、简介，点击进入该门店 | P1 |
| H-06 | 社媒/社群入口 | 「关注小红书」跳转朋友圈 Tab；「加入社群」跳转企微页 | P2 |
| H-07 | 下拉刷新 | 支持下拉刷新城市、门店、Banner 数据 | P1 |

#### 3.1.3 交互与规则

- 未登录用户可浏览首页内容；
- 城市列表、门店列表、Banner 均从服务端拉取，失败时使用本地 Mock 兜底；
- 门店点击默认进入 `packageA/store/list?storeId=&storeName=`。

### 3.2 宠物朋友圈 — `pages/msg/msg`

#### 3.2.1 页面目标

展示社区动态流，支持浏览、点赞、评论、分享，以及消息通知与发布入口。

#### 3.2.2 功能清单

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| M-01 | 动态列表 | 分页加载动态：头像、昵称、门店、时间、正文、图片/视频 | P0 |
| M-02 | 媒体预览 | 点击图片全屏预览；视频在列表内展示封面与播放控件 | P0 |
| M-03 | 点赞/取消 | 受动态 `allowLike` 控制；已点赞显示实心爱心 | P0 |
| M-04 | 评论 | 底部弹层展示评论列表，支持分页加载、发送评论、删除自己的评论 | P0 |
| M-05 | 分享 | 调用分享接口记录分享行为 | P1 |
| M-06 | 互动消息 | 顶部铃铛展示未读数，弹层列出点赞/评论等通知，点击可跳转对应动态 | P1 |
| M-07 | 发布入口 | 顶部相机图标进入发布页，需登录 | P0 |
| M-08 | 动态详情 | 点击卡片进入 `post/detail` | P0 |

#### 3.2.3 交互与规则

- 点赞、评论、发布需登录（`ensureLogin`）；
- 评论字数、敏感词由服务端校验；
- 动态若关闭评论/点赞，对应按钮置灰不可操作。

| I-06 | 右侧快捷入口 | 发布动态、退役领养、人气打榜、企微、攻略 | P1 |

| SET-05 | 联系客服 | 跳转企微页 | P1 |
| SET-06 | 账号注销 | 发起注销申请 | P2 |
| SET-07 | 退出登录 | 清除 token 并回到未登录态 | P0 |

#### 3.12.2 我的券包 `coupon/list`

- 展示可用/已用/过期优惠券；
- 券信息：标题、面额、使用条件、有效期、类型。

#### 3.12.3 赠送视频反馈 `gift/list`

- 展示用户向门店宠物赠送礼物的记录；
- 含日期、宠物、物品、备注、反馈状态（已反馈/预计反馈）。

#### 3.12.4 我的助力 `assist/list`

- 展示用户为宠物打榜、领养助力等活动记录；
- 含目标宠物、助力类型、时间、结果。

#### 3.12.5 企微/社群 `wecom/index`

- 展示企业微信二维码或社群加入引导；
- 用于客服咨询与社群运营。

## 4. 通用需求

### 4.1 登录与权限

| 场景 | 是否需登录 |
|------|------------|
| 浏览首页、朋友圈列表、商城列表、岛宅展示 | 否 |
| 点赞、评论、发布、投诉、投喂、购买、打榜、领养申请 | 是 |
| 我的页资产、菜单功能 | 是（未登录引导登录） |

### 4.2 导航与 UI 规范

- 主色调：暖色系（`#c79662`、`#FFF8F0` 等），圆角卡片 + 虚线边框（`pet-dashed`）；
- 大部分页面使用自定义导航栏 `app-navbar`；
- 全局应用名：「和它交个朋友」；
- 统一使用 `pet-page` / `pet-card` / `pet-button` 等样式体系。

### 4.3 网络与容错

- API 基址配置于 `common/config.js` 的 `APIHOST`；
- 请求封装于 `common/request.js`，Header 携带 `token`；
- 接口失败时部分页面使用 `mock-data.js` 本地数据兜底；
- 错误提示统一 Toast，表单类错误使用 `showApiErrorToast`。

### 4.4 数据字典（核心业务字段）

| 字段 | 说明 |
|------|------|
| 花瓣积分 `points` | 商城兑换、任务奖励 |
| 金币 `coins` | 岛宅集市消费 |
| 爱心值 `love` | 亲密度/打榜相关 |
| 动态审核状态 | 0 待审核 / 1 已通过 / 2 已拒绝 |
| 投诉对象类型 | 1 动态 / 2 评论 |

## 6. 页面流程图（核心路径）

### 6.1 朋友圈发布流程

```
朋友圈 Tab → 相机图标 → 登录校验 → 发布页
  → 上传媒体(≤9) + 输入正文 + 选宠物/门店
  → 提交 → 待审核 → 我的动态查看状态
```

### 6.2 投诉流程

```
动态详情 → 更多 → 投诉页 → 选类型 + 填说明 → 提交
  → 我的 → 我的投诉 → 查看记录
```

### 6.3 商城购买流程

```
商城 Tab → 商品详情 → 选规格 → 立即购买 → 微信支付
  → 支付结果页
```

### 6.4 岛宅养成流程

```
岛宅 Tab → 投喂/任务/集市 → 提升亲密度与资产
  → 常驻设置(最多2只) → 岛宅形象更新
```
