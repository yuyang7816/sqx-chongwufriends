# 用户端运行教程

按顺序做。这是给手机和网页用的应用，产品名称是「和它交个朋友」（`manifest.json` 里也可能写成「和它交朋友」）。用 HBuilderX 打开 `chongwu-uniapp` 文件夹来运行。

先按 [服务端运行教程](服务端-运行教程.md) 导入 `chongwu-server/sql/pet-full-mysql57.sql` 并启动服务端。首页门店、朋友圈、商城都依赖这个库和服务。服务端没启动时，页面也许能打开，但列表是空的，登录会失败。

## 开始之前要准备什么

安装 HBuilderX：https://www.dcloud.io/hbuilderx.html

下载「正式版」。解压或安装后，打开软件，窗口标题是 HBuilderX，就说明安装成功。

只在电脑浏览器里看时，不需要微信开发者工具。要在微信里看，再安装微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

## 第 1 步：确认连的是自己电脑上的服务端

用 HBuilderX 或记事本打开 `chongwu-uniapp/common/config.js`。文件最上面现在可能指向线上域名。本地联调改成：

```javascript
const ROOTPATH = 'http://127.0.0.1:9294/sqx_fast';
const ROOTPATH3 = 'http://127.0.0.1:9294/sqx_fast';
const UPLOADPATH = 'http://127.0.0.1:9294/sqx_fast';
```

把原来的线上地址那几行注释掉。`ROOTPATH` / `ROOTPATH3` 是接口；`UPLOADPATH` 是上传与文件访问。保存文件。

本机调试不要继续用 `https://cwjpy.xianmxkj.com`，否则数据还在线上。

## 第 2 步：用 HBuilderX 打开项目

1. 打开 HBuilderX。
2. 菜单选「文件」→「打开目录」。
3. 选中 `chongwu-uniapp` 这个文件夹。不要选它的上一级（那一层还有 `chongwu-server` 和 `chongwu_admin`），也不要只选里面的某个页面。
4. 左侧能看到 `pages`、`packageA`、`pages.json`、`manifest.json`、`common`。

## 第 3 步：在电脑浏览器里运行

1. 菜单选「运行」→「运行到浏览器」→「Chrome」。没有 Chrome 时选 Edge。
2. 第一次会下载编译器，底部控制台会出现「正在编译」。等到出现「编译成功」，浏览器会自己打开。
3. 地址以控制台里打印的为准。如果控制台里写的是别的端口，用控制台里的地址。
4. 打开后底部应能看到五个入口：**探索、朋友圈、岛宅、商城、我的**。

HBuilderX 不要关。关掉后页面会打不开。

## 第 4 步：在微信小程序里运行（可选）

电脑浏览器已经能看，可以先不做这一步。

1. 安装并打开一次微信开发者工具，用微信扫码登录。
2. 在微信开发者工具里打开「设置」→「安全设置」，打开服务端口。
3. 回到 HBuilderX，菜单「工具」→「设置」→「运行配置」，把微信开发者工具的安装路径填上。
4. 菜单「运行」→「运行到小程序模拟器」→「微信开发者工具」。

`manifest.json` 里 `mp-weixin` → `appid` 已经写了一个小程序号码。那是原项目的号码。你不是该小程序的开发成员时，微信会提示 AppID 没有权限。自己练习时，把这个 `appid` 改成你自己的小程序 AppID，或继续只用浏览器运行。

微信开发者工具里如果提示域名不合法，本地调试可以勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。`127.0.0.1` 不是微信后台配置过的合法域名，不勾选这一项，模拟器里的接口会失败。

## 怎样算成功

首页能打开，底部五个按钮能点。按键盘 `F12`，点「网络」或 Network，再按一次浏览器的刷新。列表里的请求地址应是 `127.0.0.1:9294`。出现 `cwjpy.xianmxkj.com`，说明第 1 步没有保存，或改完后没有重新点「运行到浏览器」。

库里没有门店或商品时，对应列表可能是空的。这表示接口已经通了，只是还没有业务数据。用手机号验证码登录需要短信。短信密钥没配时，验证码发不出去，可先用密码登录（若库里已有测试账号），或到管理端配短信。密钥申请见 [用户端功能说明](用户端-功能说明.md) 末尾。

## 常见问题

**运行菜单是灰的，或提示没有浏览器**  
先安装 Chrome 或 Edge，再重启 HBuilderX。项目必须用「打开目录」打开 `chongwu-uniapp`。

**一直停在「正在编译」，或浏览器是白屏**  
等控制台不再滚动。若出现红色报错，把第一行红色文字保留下来。常见原因是打开的文件夹不是 `chongwu-uniapp`，或编译器还没下完。公司网络拦截下载时，换一个网络再运行一次。

**首页能开，但没有数据，登录失败**  
服务端没有启动，或 `common/config.js` 仍是原来的 `https://` 地址。先看服务端窗口是否还有「宠物启动成功...」，再改第 1 步，然后重新运行到浏览器。

**点上传后图片没保存**  
上传地址还指向线上，或管理端「系统配置」里文件存储不可用。先确认 `UPLOADPATH` 指向本机 `9294`，再在管理端检查上传配置。

**微信开发者工具提示 AppID 无效或没有权限**  
换成你自己的小程序 AppID，或改用浏览器运行。
