# 管理端运行教程

按顺序做。这是电脑浏览器里的后台，不是手机应用。代码在 `chongwu_admin` 文件夹。对应产品是「和它交个朋友」。

先按 [服务端运行教程](服务端-运行教程.md) 把数据库导入并启动服务端。服务端窗口里要已经出现「宠物启动成功...」，并且那个窗口不能关。服务端没启动时，这个网站打得开，但验证码图片是裂的，登录会失败。

## 开始之前要准备什么

安装 Node.js **18 或更高**：https://nodejs.org/

这个后台是 **Vue 3 + Vite 5 + Element Plus**，用 Node 18 / 20 的长期支持版即可。

安装时勾选添加到 PATH。安装完成后，重新打开 PowerShell，输入：

```powershell
node -v
npm -v
```

两行都有版本号才算成功，例如 `v18` 或 `v20`，以及 `8.x` 以上。只看到「不是内部或外部命令」时，关掉窗口再开一次；还是没有，就重新安装 Node.js 并勾选 PATH。

浏览器使用 Chrome 或 Edge。

## 第 1 步：确认连的是自己电脑上的服务端

开发时接口地址写在：

`chongwu_admin/src/utils/tool.js`

打开后找到 `getApiBaseUrl`。仓库默认常指向线上管理端域名。本地联调时，改成下面这样（注释掉线上那行，打开本地那行）：

```javascript
export function getApiBaseUrl() {
  const fromEnv = import.meta.env?.VITE_API_BASE_URL
  // 本地业务 API（需先启动 Redis + 后端 9294）：
  const baseUrl = fromEnv || 'http://127.0.0.1:9294/sqx_fast/'
  // 线上业务 API：
  // const baseUrl = fromEnv || `${ONLINE_FILE_DOMAIN}/sqx_fast/`
  return baseUrl.endsWith('/') ? baseUrl : `${baseUrl}/`
}
```

也可以不改文件，在启动前设置环境变量 `VITE_API_BASE_URL=http://127.0.0.1:9294/sqx_fast/`。

图片上传如果仍指向线上，本地只测登录和列表时可以先不动；要测本机上传时，把 `getUploadBaseUrl` 也切到本机服务端，并确保管理端「系统配置」里文件存储可用。

改完之后，如果网站已经在运行，要先停掉再启动，修改才会生效。

## 第 2 步：安装依赖

在 `chongwu_admin` 文件夹里打开 PowerShell（在文件夹空白处按住 Shift，右键，选「在此处打开 PowerShell 窗口」或「在终端中打开」），执行：

```powershell
npm install
```

第一次可能要几分钟到十几分钟。结束时没有红色 `npm ERR!`，并且这个文件夹里出现 `node_modules`，就成功了。

## 第 3 步：启动网站

还是在 `chongwu_admin` 文件夹里执行：

```powershell
npm run dev
```

窗口里会出现本地地址。默认端口是 **5173**。浏览器没有自动打开时，手动打开：

http://localhost:5173

登录页上应能看到一张验证码图片。看不清就点图片换一张。验证码来自本机服务端。图片是裂的，说明第 1 步的地址不对，或服务端没有启动。

这个 PowerShell 窗口也要一直开着。

## 怎样算成功

使用导入库里的演示账号登录。用户名是 `admin`，密码是 `123456`。登录成功后进入仪表盘或数据页，左侧能看到菜单，例如宠物业务（门店、档案、社区、岛宅、商城等）、用户、系统管理。某个菜单没有出现，是这个账号的角色里没勾选它，到「角色管理」里勾上再重新登录。

门店、商品列表是空的，不代表后台没连上。需要在后台录入，或用户端产生数据之后，这里才会有内容。

## 常见问题

**`npm` 不是内部或外部命令**  
Node.js 没装好，或安装后没有重新打开 PowerShell。

**浏览器打不开 localhost:5173**  
看 `npm run dev` 的窗口是否还在。窗口里如果写的是别的端口，用窗口里打印的那个地址。

**验证码不显示，或登录提示网络错误**  
服务端没启动，或 `getApiBaseUrl` 仍指向线上域名。按键盘 `F12`，点「网络」或 Network，再点一次登录。请求应发到 `127.0.0.1:9294`。改完后在运行窗口按 `Ctrl+C` 停掉，再执行一次 `npm run dev`。

**`Port 5173 is in use`**  
5173 已被占用。关掉之前的管理端窗口再启动。

**登录提示验证码不正确**  
图片上的字要和输入完全一致，区分大小写。点图片换一张再试。服务端窗口如果已经关掉，验证码对了也登不进去。
