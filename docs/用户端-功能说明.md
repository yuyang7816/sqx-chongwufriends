# 用户端功能说明

用户端是养宠用户在手机或电脑网页里打开的那个应用。产品名称是「和它交个朋友」。底部一直有五个按钮：**探索、朋友圈、岛宅、商城、我的**。

下面按「打开后能点到什么」来写。每一处都说明：点进去做什么，以及会不会真的连到微信、支付宝、短信这些外面的服务。

## 这个端是给谁用的

- **养宠用户 / 游客**：浏览门店与宠物、发朋友圈、岛宅养成、商城购物、申请领养。
- **平台工作人员不使用这个应用。** 审核动态、处理领养、改 Banner 和商品，在电脑上的管理端做。

核心主张是 **理性养宠、降低遗弃**：通过门店互动、社区与虚拟养成，引导用户更负责任地养宠。

## 探索（首页）

打开就是探索首页。

- **城市切换**：顶部展示当前城市，切换后刷新门店与 Banner。
- **运营 Banner**：展示活动或主张图，点击跳转配置链接或业务页（如领养）。
- **线下门店**：按城市展示门店入口，点击进入门店小伙伴列表。
- **社媒 / 社群入口**：如关注小红书、加入企微社群等，具体以页面配置为准。

未登录也可浏览首页。列表数据来自服务端；库里没有门店时，首页门店区会是空的。

## 宠物朋友圈

底部「朋友圈」是社区动态流。

- **动态列表**：头像、昵称、门店、时间、正文、图片 / 视频。
- **点赞、评论、分享**：受动态开关控制；点赞评论一般需要登录。
- **消息铃铛**：未读互动通知。
- **发布**：顶部入口进入发布页，可上传图片或视频、填写正文，提交后可能进入待审核。
- **动态详情 / 我的动态**：查看完整内容与审核状态；被拒绝时可看到原因。
- **投诉**：对不当内容提交投诉类型与说明。

朋友圈内容存在自己的服务器。管理端「社区动态」「投诉」用来审核和处理。

## 岛宅

底部「岛宅」是虚拟宠物养成主场景。

- **资产展示**：积分、花瓣、爱心等数值。
- **岛宠形象**：常驻宠物、心情、亲密度。
- **快捷投喂**：水碗 / 食盆等投喂动作，影响宠物状态。
- **侧栏入口**：投喂选品、常驻设置、任务中心、宠物集市；以及发布动态、退役领养、人气打榜、企微、攻略等。

岛宅玩法主要改自己数据库里的资产与状态，不经过微信。部分投喂若涉及付费商品，才会走到支付。

## 商城

底部「商城」浏览商品。

- **分类与商品列表**：封面、名称、价格、积分价等。
- **商品详情**：规格选择、下单。
- **积分兑换 / 兑换记录**：用积分换周边时走兑换流程。
- **支付结果页**：付款完成后的结果展示。

付钱规则见下面「付款」。

## 我的

未登录时引导去登录。登录后展示头像、昵称、资产概览。

常见入口：

- **我发布的朋友圈**
- **我的助力**
- **赠送视频反馈**
- **我的券包**
- **周边兑换记录**
- **我的投诉**
- **设置**（资料、协议、注销等）

资产数字来自服务端，不是微信钱包。

## 登录、注册和找回密码

登录页常见方式：

- **手机号 + 密码**
- **手机号 + 短信验证码**（未注册可能自动注册，以接口为准）
- **微信一键登录**（小程序环境，依赖微信配置）
- **忘记密码 / 注册**

没配短信密钥时，验证码发不出去。没配微信 AppId / 密钥时，微信登录会失败，但仍可尝试密码登录。

## 门店小伙伴

从首页门店进入，可按汪星人 / 喵星人查看门店宠物卡片，点进档案详情。

## 退役领养

- **列表**：筛选犬猫、搜索、查看卡片。
- **详情**：完整档案、门店信息等。
- **申请表单**：提交后进入待审核，管理端处理。

领养不自动完成过户；审核通过与否以管理端操作为准。

## 人气打榜

为门店宠物助力打榜，查看排名。需登录。榜单规则（周期重置、奖励）以页面说明与后台配置为准。

## 养宠攻略

阅读平台发布的养宠内容。文章来自管理端攻略管理。

## 付款

商城下单、部分付费投喂或活动，可选的付款方式取决于后台是否配齐：

- **余额 / 积分 / 金币**：扣站内资产，不经过微信或支付宝。资产不够就不能完成。
- **微信支付**：拉起微信支付。需要商户号、密钥，以及小程序 AppId。
- **支付宝**：拉起支付宝。需要应用编号和密钥。

付成功后，微信或支付宝会通知服务端，订单才会变成已支付。付完钱立刻关页面、通知还没到时，订单可能要等一会儿才变。

## 这个端真正会连到外面的服务

短信、微信、支付宝、图片存储的密钥填在管理端「系统配置」，由服务端去调用。只改用户端页面上的字，不会变成已经开通。

| 你在页面上做的事 | 要申请的服务 | 官网 | 填在哪里 | 没填密钥时 |
|---|---|---|---|---|
| 注册、验证码登录、找回密码 | 短信服务商（短信宝 / 阿里云 / 腾讯云等） | https://www.smsbao.com/ 、 https://www.aliyun.com/product/sms 、 https://cloud.tencent.com/product/sms | 管理端「系统配置」 | 验证码发不出去 |
| 微信一键登录 | 微信公众平台小程序 | https://mp.weixin.qq.com/ | 管理端「系统配置」 | 微信登录失败 |
| 微信支付 | 微信支付商户平台 | https://pay.weixin.qq.com/ | 管理端「系统配置」 | 无法拉起微信支付 |
| 微信支付还要小程序 AppId | 微信公众平台 | https://mp.weixin.qq.com/ | 管理端「系统配置」 | 只有商户号时仍然付不了 |
| 支付宝付款 | 支付宝开放平台 | https://open.alipay.com/ | 管理端「系统配置」 | 无法拉起支付宝 |
| 头像、动态图片 / 视频 | 本机存储或阿里云 OSS | https://www.aliyun.com/product/oss | 管理端「系统配置」 | 上传失败，媒体保存不住 |
| 加入企微社群等 | 企业微信相关配置 | https://work.weixin.qq.com/ | 管理端相关配置页 | 入口打不开或无效 |

短信开通其中一家即可。图片存储按后台选定方式配置。

下面这些不用申请外面的 Key，服务端和数据库就绪就能用：

- 浏览门店、宠物档案、攻略、已上架商品。
- 朋友圈浏览；登录后的点赞评论（内容存在自己库里）。
- 岛宅养成、任务、集市（站内资产足够时）。
- 提交领养申请、投诉（审核在管理端）。
- 用站内积分 / 金币兑换或支付（资产足够时）。

下面这些看起来像外面的服务，但当前主要是展示或站内逻辑：

- 复制微信号、查看社群二维码：是展示，不会自动加好友。
- 打榜助力：记在自己的数据库里。
- 底部界面组件（uView Plus）：只负责长得像一个应用，不负责收款或发短信。
