# 管理端功能说明

管理端是给平台工作人员用的网站，在电脑浏览器里打开。养宠用户不使用这个网站。它用来看经营和用户、审核动态与领养、处理订单与优惠券，以及填写微信、支付宝、短信、图片存储这些外面服务的账号。

对应产品是「和它交个朋友」。工作人员登录后，左侧是菜单。能看到哪些菜单，由管理员给这个账号分配的权限决定。没有权限的菜单不会出现。

下面的菜单名称来自导入的数据库和 `chongwu_admin/src/views`。如果你后来在「菜单管理」里改过名字，以你屏幕上看到的为准。

## 登录

登录页要填账号、密码，还要看一张图片验证码。看不清就点图片换一张。验证码由服务端生成。服务端没启动时，图片是裂的，登录也会失败。

导入 `pet-full-mysql57.sql` 之后，演示账号是 `admin`，密码是 `123456`。开源使用时建议只使用 `admin`，或在「管理员列表」里自己新建。

## 登录之后第一眼：仪表盘 / 数据中心

登录后的首页用来看平台概况，数字来自自己的数据库，不连接外面的报表公司。

具体有哪些数字，以页面上显示的为准。它用来知道有没有新用户、订单和待处理事项，不是在这里替用户付款。

## 用户

### 用户列表 / 用户详情

看注册用户。可进入用户详情，从资产、岛宅、投喂、优惠券、订单等维度查看该用户（用户 360）。有权限时可处理认证、注销申请、消息等。

### 注销申请

用户在设置里申请注销账号后，记录出现在这里。这是人工处理注销，不是用户一点、账号立刻从库里消失。

## 宠物业务

### 城市与门店

维护城市、线下门店。用户端探索首页按城市拉取门店，数据来自这里。

### 宠物档案 / 品种

维护门店宠物档案、品种字典。用户端「门店小伙伴」、领养列表展示的宠物信息，来自这里保存的资料。

### 社区动态

用户发布的朋友圈动态。可审核通过 / 拒绝，处理不合适内容。用户端投诉和动态是配套的：用户在手机上投诉，工作人员在后台看。

### 投诉与投诉类型 / 敏感词

配置投诉类型、处理投诉单；维护敏感词，避免不当内容进入社区。

### 岛宅

维护岛宠、任务、集市商品等。影响用户端岛宅养成、投喂与任务奖励。

### 投喂订单

查看用户投喂相关订单记录。

### 领养审核

用户提交退役领养申请后，在这里通过或拒绝。审核结果会影响用户端申请状态。

### 商城

维护商品分类、SPU、SKU 规格、商城订单、兑换记录、优惠券及发放。用户端商城页读的是这些配置与商品。

### 支付订单 / 支付流水

核对谁买了、付了没有、支付通道回调是否成功。真正扣款发生在用户付款的那一刻，这些页面是事后查看。

### 人气榜 / 攻略

维护打榜相关数据；维护养宠攻略分类与文章。用户端攻略列表读这里。

### 首页装修 / 社媒入口

决定用户端首页 Banner、装修与社群相关展示。改完保存后，用户下次打开首页才会变。

## 订单、优惠券、会员与财务

视菜单权限，还可能看到订单中心、优惠券制作与发放、会员与积分相关页、财务中心等。用来核对经营数据和处理资金相关记录。

用户提现或人工打款类操作，以页面实际按钮为准；是否自动调用微信 / 支付宝打款，取决于服务端是否接入对应能力。常见情况是后台改状态，打款仍需人工处理。

## 系统配置：外面那些服务的账号都在这里

这是和第三方关系最大的一页。短信、微信支付、支付宝、图片存到哪一家，都在「系统配置」里改。

改完要保存。用户端下次请求才会用新的密钥。只在用户端改文字，不会变成已经开通了支付。

常见配置项：

- **短信**：短信宝 / 阿里云 / 腾讯云等，开通其中一家即可
- **微信支付**：商户号、密钥，以及小程序 AppId
- **支付宝**：应用编号和密钥
- **文件存储**：本机上传目录，或阿里云 OSS

缺一项，对应功能在用户端会失败（验证码发不出、付不了款、图片存不住）。

## 系统管理

「系统管理」是给工作人员账号用的，养宠用户看不到：

- **管理员列表**：后台登录账号。可以新增工作人员。
- **角色管理**：一组权限的名字，例如只让某个人看用户、不能改财务。
- **菜单管理**：左侧有哪些菜单。改错了可能导致某个页面从菜单里消失。
- **字典**：下拉选项一类基础数据。
- **升级配置**：手机 App 要不要提示升级。只做网页预览时可以先不管。

## 这些页面是框架留下的

工程里还能看到商户、教练、音乐、展柜等部分页面或接口模块，那是后台模板历史能力。左侧菜单里没有的就不用找；日常「和它交个朋友」运营以宠物业务、用户、订单、系统配置为主。

## 和用户端怎么配合

管理端不自己保存订单和审核结果。它把操作发给服务端，服务端再写入数据库。所以：

- 服务端没启动时，验证码出不来，登录会失败。
- 在这里改完门店、商品、Banner、攻略并保存后，用户端下次打开才会看到。
- 外面的密钥只配在「系统配置」。用户端没有地方填写微信支付商户号。
