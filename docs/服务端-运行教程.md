# 服务端运行教程

按顺序做。做完一步，看到文中写的成功标志，再做下一步。

服务端是三个端里要第一个启动的。代码在 `chongwu-server` 文件夹。数据库不用自己建表，项目里已经带了一份完整初始化脚本：`chongwu-server/sql/pet-full-mysql57.sql`。

## 开始之前要准备什么

在自己的 Windows 电脑上安装下面四个软件。安装时勾选「添加到 PATH」或「Add to PATH」。

| 软件 | 用什么版本 | 怎样确认已经装好 |
|---|---|---|
| JDK | 1.8（也叫 Java 8） | 开始菜单打开「命令提示符」或 PowerShell，输入 `java -version`，能看到 `1.8.0` |
| Maven | 3.6 或更高 | 输入 `mvn -v`，能看到 `Apache Maven 3` |
| MySQL | 5.7 或 8.0 | 开始菜单里能找到「MySQL Command Line Client」或「MySQL 8.0 Command Line Client」 |
| Redis | 5.0 或更高 | 安装后能启动服务；本教程默认本机 `127.0.0.1:6379` |

Java 不要装成 11、17 或 21。装错版本时，先卸掉，再装 1.8。下载可用 Adoptium 的 Temurin 8：https://adoptium.net/temurin/releases/?version=8

Maven 下载：https://maven.apache.org/download.cgi 。解压后把里面的 `bin` 文件夹加到 PATH。关掉原来的 PowerShell，再打开一个新的，`mvn -v` 才能看到版本。

MySQL 安装过程中会让你给 `root`（或你自己的账号）设一个密码，还会让你确认端口。把账号、密码和端口记在纸上。Windows 上新装的 MySQL，端口通常是 **3306**。

Redis 本项目通过 Redisson 连接。开发配置写在 `application-dev.yml` 的 `redisson` 段：地址 `127.0.0.1`，端口 `6379`，库号 `5`。启动服务端前先把 Redis 跑起来。Windows 可用 Memurai、Redis for Windows，或 Docker 启动一个 Redis 容器。

## 第 1 步：新建空数据库

这份 SQL 文件里是表和数据，它不会自己创建名叫 `chongwujiaopengyou` 的库。要先建库，再导入。

1. 打开开始菜单里的 MySQL 命令行。
2. 输入你安装 MySQL 时设的账号密码，回车。看到 `mysql>` 才算连上。
3. 把下面这一整行复制进去，回车：

```sql
CREATE DATABASE IF NOT EXISTS chongwujiaopengyou DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

4. 再输入：

```sql
SHOW DATABASES;
```

列表里有 `chongwujiaopengyou` 就成功了。输入 `exit` 退出。

如果提示 `Access denied`，是账号或密码错了，用安装 MySQL 时设的那个账号密码重来。

## 第 2 步：导入项目里的数据库文件

文件位置（相对整个项目文件夹）：

`chongwu-server/sql/pet-full-mysql57.sql`

这是宠物业务完整初始化脚本（兼容 MySQL 5.7），里面已经有框架表、业务表、管理端菜单、系统配置和测试数据。导入会写入大量表，所以请导入到上一步新建的空库，不要导入到别的业务库。

以后如果仓库里还有按日期命名的增量补丁（同目录下其它 `*.sql`），可按需要再执行；首次空库初始化优先用这份完整脚本。

在项目根目录（能同时看到 `chongwu-server`、`chongwu_admin`、`chongwu-uniapp` 的那一层）打开 PowerShell。把 `-u` 后面的用户名、`-p` 后面的密码、`-P` 后面的端口，改成你的 MySQL。下面这个例子按常见本机默认来写：用户 `root`，密码 `123456`，端口 `3306`。

```powershell
$mysql = "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe"
& $mysql -uroot -p123456 -P3306 --default-character-set=utf8mb4 chongwujiaopengyou -e "source $($PWD.Path -replace '\\','/')/chongwu-server/sql/pet-full-mysql57.sql"
```

执行时窗口会停一会儿。结束时没有 `ERROR`，再执行下面这句，能看到很多表名，就说明导入成功：

```powershell
& $mysql -uroot -p123456 -P3306 --default-character-set=utf8mb4 -e "USE chongwujiaopengyou; SHOW TABLES;"
```

如果提示找不到 `mysql.exe`，到 `C:\Program Files\MySQL\` 下面找到实际的 `mysql.exe`。装的是 5.7 时，路径里通常是 `MySQL Server 5.7`。把上面第一行的路径换成你的路径。

用 Navicat 也可以：连接到本机 MySQL，双击打开 `chongwujiaopengyou`，菜单选「运行 SQL 文件」，选中 `chongwu-server/sql/pet-full-mysql57.sql`，编码选 UTF-8，点开始。底部显示成功即可。

## 第 3 步：让程序连接你自己的 MySQL 和 Redis

本地开发建议读 **dev** 配置。

打开这个文件：

`chongwu-server/sqx-application/src/main/resources/application-dev.yml`

找到数据源这几行（仓库里可能是占位符，要改成你本机真实账号）：

```yaml
url: jdbc:mysql://127.0.0.1:3306/chongwujiaopengyou?useUnicode=true&characterEncoding=utf-8&useSSL=false
username: 用户名
password: 密码
```

按你的环境改：

- 地址一般保持 `127.0.0.1`，库名保持 `chongwujiaopengyou`。
- 你的 MySQL 端口不是 3306 时，把 URL 里的 `3306` 改成实际端口。
- `username`、`password` 改成你安装 MySQL 时设的账号密码。

再看同文件里的 Redis：

```yaml
redisson:
  host: 127.0.0.1
  port: 6379
  password:
  database: 5
```

本机 Redis 无密码时，`password` 可以留空。有密码就填上。库号默认 `5`，与其它项目冲突时再改。

保存 `application-dev.yml`。

再打开 `chongwu-server/sqx-application/src/main/resources/application.yml`，把激活环境改成：

```yaml
active: dev
```

是 `dev` 时，启动读的就是上面那份 `application-dev.yml`。如果继续用 `prod`，则会读 `application-prod.yml`（里面可能是远程库），本地联调容易连错。

## 第 4 步：启动 Redis

先确认 Redis 已在本机监听 `6379`（或你在 yml 里改过的端口）。没启动 Redis 时，服务端常会在连接 Redisson 阶段失败。

## 第 5 步：启动服务端

在 `chongwu-server` 文件夹里打开 PowerShell（在文件夹空白处按住 Shift，右键，选「在此处打开 PowerShell 窗口」或「在终端中打开」），执行：

```powershell
mvn clean package -DskipTests
mvn -pl sqx-application -am spring-boot:run
```

第一次会下载很多依赖，可能要 10 到 30 分钟，窗口要一直开着。看到这行字才算启动成功：

```text
宠物启动成功...
```

不要关闭这个窗口。关闭后服务端就停了。

用 IDEA 也可以：

1. 用 IDEA 打开 `chongwu-server`（选有根 `pom.xml` 的那一层）。
2. 等右下角 Maven 导入结束。Project SDK 选 1.8。
3. 菜单「File」→「Settings」→「Plugins」，搜索并安装 Lombok，然后勾选「Enable annotation processing」。很多实体类用了 Lombok，没装插件时会报找不到 `getXxx`。
4. 打开 `sqx-application/src/main/java/com/sqx/SqxApplication.java`，点左侧绿色三角。
5. 控制台同样要出现「宠物启动成功...」。

## 怎样算成功

浏览器打开：

http://127.0.0.1:9294/sqx_fast/doc.html

能看到 Knife4j 接口文档。如果这个页面打不开，只要启动日志里有「宠物启动成功...」，并且接下来管理端能打开登录页上的验证码图片，也算服务端已经就绪。

后台登录账号是导入库里的演示账号：用户名 `admin`，密码 `123456`。这是管理端登录密码，和 MySQL 的 root 密码不是同一件事。短信、微信、支付宝、图片存储这些密钥需要自己到对应官网申请，再填进管理端「系统配置」。申请入口写在 [用户端功能说明](用户端-功能说明.md) 末尾。

## 常见问题

**`java` 不是内部或外部命令，或版本不是 1.8**  
Java 没装好，或装成了更高版本。安装 Temurin 8，关掉 PowerShell 再打开，重新执行 `java -version`。

**`mvn` 不是内部或外部命令**  
Maven 的 `bin` 没有加到 PATH。加完后必须关掉 PowerShell 再开一次。

**`Access denied for user`**  
MySQL 账号密码和 `application-dev.yml` 里的 `username` / `password` 不一致。把 yml 改成你安装时设的账号密码，导入命令里 `-u`、`-p` 也改成同一个。

**`Communications link failure`，或提示连不上 3306**  
本机 MySQL 没有监听这个端口，或服务没开。把 yml 里的端口和导入命令里的 `-P` 改成同一个，再启动。

**`Unknown database 'chongwujiaopengyou'`**  
第 1 步的建库没有成功。回到命令行把 `CREATE DATABASE` 再执行一次。

**导入 SQL 时中文变问号**  
命令里要带 `--default-character-set=utf8mb4`。用 Navicat 时，运行 SQL 文件的编码选 UTF-8。

**启动报找不到 `getXxx`、`setXxx` 或 `log`**  
IDEA 没装 Lombok，或没打开注解处理。按第 5 步安装插件后再编译。用 Maven 启动时一般不会出现这个问题。

**`Port 9294 was already in use`**  
9294 端口已经被占用。把之前开着的服务端窗口关掉，或在任务管理器里结束对应的 Java 进程，然后再启动。

**连不上 Redis / Redisson 报错**  
先启动 Redis，确认 `host`、`port`、`password`、`database` 和 `application-dev.yml` 一致。

**明明改了库名，还是连到远程库**  
检查 `application.yml` 里的 `spring.profiles.active` 是否为 `dev`。仍是 `prod` 时读的是 `application-prod.yml`。
